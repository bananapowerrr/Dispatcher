# UI

Точка входа: `python dispatcher_ui.py`

## Вкладки

| Вкладка | Назначение |
|---------|------------|
| Чат | Главный канал задач (desktop queue) |
| Логи / метрики | Очередь, health |
| Настройки | Провайдеры, воркеры, **политика** |
| Телефон | Опциональный file-bus |
| Diff / PEV / … | Просмотр правок и планов |

## Команды в чате

`/help` `/status` `/workers` `/clear`

## Запуск диспетчера из UI

Кнопка **▶ Запустить диспетчер** или отдельно в терминале.
